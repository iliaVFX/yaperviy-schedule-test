# Телепрограмма ЯПервый

Содержимое этой папки предназначено для отдельного GitHub-репозитория с основной веткой main. Для запуска включите Settings → Pages → Source → GitHub Actions и запустите workflow «Телепрограмма» (Actions → Run workflow). Откройте адрес из результата deploy.

Добавьте сотрудников с доступом Write. На сайте нажмите «Загрузить Word-файл», выберите недельный .docx с годом в имени и подтвердите Commit changes в main. При исправлении недели заменяйте файл с тем же именем. Для ветки с обязательным ревью опубликуйте изменения через pull request в main. Исходники Word будут видны всем, у кого есть доступ к репозиторию, в публичном репозитории — всем.

Сборка проверяет таблицы документа и создаёт schedule.json совместимого с приложением формата. При ошибке откройте журнал Actions. Предыдущая версия сайта останется доступна. Файл seed.json содержит опубликованную в приложении сетку 9–22 ноября 2026. Новые документы заменяют соответствующие недели. В выдачу попадают до четырёх опубликованных недель начиная с текущей. По истечении всего периода приложение скрывает устаревшую сетку.

В настройке iOS-приложения BROADCAST_SCHEDULE_URL укажите полный HTTPS-адрес ссылки «JSON для приложения» и один раз пересоберите приложение.

Локальный просмотр: python3 build.py && python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
